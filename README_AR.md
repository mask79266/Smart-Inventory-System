# المخزون الذكي — مشروع أندرويد أولي

هذا مشروع بداية لتطبيق أندرويد أصلي (Kotlin + Jetpack Compose) لإدارة المخزون. ليس APK جاهزًا بعد؛ يلزم إعداد مشروع Firebase الخاص بالمالك، ثم بناء التطبيق واختباره.

## الوظائف المضمنة في هذه المرحلة
- واجهة عربية RTL أولية.
- شاشة تسجيل دخول بالبريد وكلمة المرور عبر Firebase Authentication.
- شاشة رئيسية أولية للبحث وعرض الأصناف من Cloud Firestore.
- نموذج بيانات مطابق للأعمدة الأساسية من ملف Excel التجريبي.
- نقطة استقبال أولية للإشعارات عبر Firebase Cloud Messaging.
- قائمة سماح للمستخدمين مخططة عبر مستندات `allowedUsers/{email}` في Firestore.

## إعداد Firebase
1. أنشئ مشروعًا في Firebase Console.
2. أضف تطبيق Android بمعرّف الحزمة `com.abutameem.inventory`.
3. نزّل `google-services.json` وضعه داخل مجلد `app/`.
4. فعّل Email/Password في Authentication.
5. أنشئ Cloud Firestore.
6. لا تجعل قاعدة البيانات عامة. استخدم قواعد أمان تتحقق من تسجيل الدخول وقائمة السماح.
7. إعداد الإشعارات الفعلية يحتاج إلى وظيفة خلفية موثوقة ترسل FCM عند إنشاء/تعديل صنف. لا تضع مفتاح إرسال FCM داخل التطبيق.

## استيراد بيانات Excel
ملف Excel التجريبي يحتوي على ورقتين: `المخزون` (12 عمودًا) و`سجل الإشعارات` (3 أعمدة). يلزم تنفيذ استيراد مرة واحدة إلى Firestore مع الحفاظ على `ID` كمعرّف ثابت، والتحقق من مسارات الصور؛ لا تُرفع الصور تلقائيًا من مسارات AppSheet إلا بعد تحديد مكانها وصلاحياتها.

## البناء
افتح المجلد في Android Studio حديث، ثم Sync Gradle. بعد إضافة `google-services.json`، اختر Build > Build APK(s).
